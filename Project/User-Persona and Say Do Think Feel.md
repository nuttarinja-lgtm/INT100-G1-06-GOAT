##  Say-Do-Think-Feel Framework (วิเคราะห์ Persona)

กรอบการวิเคราะห์พฤติกรรมเชิงลึกของกลุ่มเป้าหมาย เพื่อใช้ในการออกแบบระบบและฟีเจอร์ที่ตอบโจทย์ความต้องการที่แท้จริง:

| มิติ (Dimension) | รายละเอียดพฤติกรรมและเสียงสะท้อนจากผู้ใช้ (Insights) |
| :--- | :--- |
| **Say (สิ่งที่พูดออกมา)** | (ตัวอย่าง)<br>• *"หนู/ผมยังลังเลอยู่เลยว่าควรเลือกยื่นวิศวะคอมพิวเตอร์หรือสาขาไอทีดี"*<br>• *"กังวลเรื่องคะแนนสอบและพอร์ตโฟลิโอว่าจะทำเสร็จและส่งทันกำหนดการไหม"*<br>• *"อยากได้ระบบหรือเครื่องมือที่ช่วยแนะนำโครงสร้างพอร์ตโฟลิโอที่ตรงกับเกณฑ์ TCAS"* |
| **Do (การกระทำที่แสดงออก)** | (ตัวอย่าง)<br>• ใช้เวลาค้นหาข้อมูลรีวิวคณะและหลักสูตรต่างๆ ของมหาวิทยาลัยเป้าหมายผ่านอินเทอร์เน็ต<br>• ลงมือเขียนโปรแกรม ฝึกออกแบบ UI บน Figma และเก็บสะสมเกียรติบัตรการแข่งขัน<br>• ปรึกษากับคุณครูแนะแนวและรุ่นพี่ที่สอบติดในรอบพอร์ตปีก่อนหน้า |
| **Think (ความคิดและความเชื่อ)** | (ตัวอย่าง)<br>• คิดว่าการเลือกคณะและมหาวิทยาลัยในรอบนี้คือจุดเปลี่ยนสำคัญของชีวิตการทำงานในอนาคต<br>• เชื่อว่าหากมีพอร์ตโฟลิโอที่มีโปรเจกต์เชิงปฏิบัติจริง (เช่น Mobile App หรือ AI Project) จะช่วยเพิ่มโอกาสสอบติดสูงมาก<br>• กังวลว่าโปรไฟล์และความสามารถของตนเองอาจจะยังโดดเด่นไม่พอเทียบกับผู้สมัครคนอื่น |
| **Feel (อารมณ์และความรู้สึก)** | (ตัวอย่าง)<br>• **ความวิตกกังวล (Anxiety):** กลัวการตัดสินใจผิดพลาด กลัวคณะที่เลือกเรียนแล้วไม่สนุก และกลัวผิดหวังในรอบพอร์ตโฟลิโอ<br>• **ความมุ่งมั่น (Determination):** อยากพิสูจน์ความสามารถของตัวเองผ่านโปรเจกต์และผลงานที่ตั้งใจทำ<br>• **ความคาดหวัง (Expectation):** หวังว่าจะได้ระบบหรือตัวช่วยที่ทำให้การเตรียมตัวสอบและการทำพอร์ตเป็นระบบระเบียบมากขึ้น |
