# 2. User Persona 

 เป็นตัวแทนของกลุ่มเป้าหมาย  ที่อยู่ในช่วงเตรียมตัวศึกษาต่อหรือหาความต้องการ ในการเลือกมหาวิทยาลัย เพื่อช่วยให้เข้าใจปัญหา ความต้องการ และพฤติกรรมเชิงลึกได้อย่างแม่นยำ

---

## 🎨 2. สายแฟ้มสะสมผลงาน Portfolio

นักเรียนกลุ่มนี้มุ่งเน้นการจัดทำแฟ้มสะสมผลงาน (Portfolio) เพื่อยื่นในรอบ T-CAS 1 โดยให้ความสำคัญกับการเก็บผลงาน กิจกรรม 

|  | เฟียส  |  เฟิร์ส  |  ไหม  |
| :--- | :--- | :--- | :--- |
| **เพศ** |  นักเรียนหญิง  |  นักเรียนหญิง  |  นักเรียนหญิง  |
| **อายุ / ชั้นปี** | ม.6 | ม.6 | ม.6 |
| **งานอดิเรก** | ฟังเพลง, ไปคอนเสิร์ต | ดูซีรีส์ | ฟังเพลง |
| **วิชาที่ชอบ** | ภาษาอังกฤษ | ภาษาจีน  | ภาษาอังกฤษ |
| **เป้าหมายคณะ/มหาลัย** | วารสารศาสตร์ มหาวิทยาลัยธรรมศาสตร์ | BMCI มหาวิทยาลัยธรรมศาสตร์ | สังคมศาสตร์และมนุษยศาสตร์ มหิดล |
| **เป้าหมายในอนาคต** | ทำงานเบื้องหลัง / ทำธุรกิจส่วนตัว | ทำงานรายได้สูงและสบาย | ทำงานที่รายได้ดีและชอบ |
| **Pain Point** | **ยังไม่มีผลงานใส่ Portfolio** | **การเตรียม Portfolio & คะแนนสอบ** | **การทำ Portfolio & เนื้อหา A-Level** |

##  Say-Do-Think-Feel Framework 


|  |  |
| :--- | :--- |
| **Say** | •  กังวลเรื่องการเตรียมตัวสอบไม่ทัน<br>• การทำ Portfolio ที่ยังไม่มีผลงาน<br>• คะแนนสอบ (A-Level)ที่อาจไม่ถึงเป้าหมาย |
| **Do** | • ใช้เวลาว่างไปกับสื่อบันเทิงและการพักผ่อนเพื่อลดความตึงเครียดจากการเรียน<br>• แสดงออกอย่างเป็นกันเอง ยิ้มแย้ม และหัวเราะ |
| **Think** | • ส่วนใหญ่มองว่าความสำเร็จในอนาคตวัดจากความมั่นคงทางการเงินและผลตอบแทนที่คุ้มค่า<br>• ทุกคนรู้สึกว่าช่วงชั้นนี้ เป็นช่วงเวลาที่ต้องเร่งเตรียมตัวสอบเข้ามหาวิทยาลัย |
| **Feel** | • รู้สึกสนุกสนานและผ่อนคลายเมื่อพูดถึงไลฟ์สไตล์ งานอดิเรก หรือเรื่องความฝัน<br>• รู้สึกกดดัน กังวล เกี่ยวกับเรื่องเวลา การทำ Portfolio และผลการสอบเข้ามหาวิทยาลัย |
