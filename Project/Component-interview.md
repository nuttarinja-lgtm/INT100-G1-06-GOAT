# 1. User Interview (การสัมภาษณ์กลุ่มเป้าหมาย)

หน้านี้รวบรวมชุดคำถามสำหรับการสัมภาษณ์กลุ่มเป้าหมาย และการวิเคราะห์ข้อมูลดิบเชิงพฤติกรรม

##  Interview Script (ชุดคำถาม)
1. **คำถามพฤติกรรมและแรงจูงใจ:** งานอดิเรกที่ที่น้องชอบใช้เวลากับสิ่งๆนั้นมากที่สุดคืออะไรและเพราะอะไรถึงชอบทําสิ่งนั้น
2. **คำถามด้านความชอบและความถนัดทางวิชาการ:** วิชาไหนที่น้องคิดว่าชอบที่สุดและคิดว่าเราชอบวิชานั้นเพราะอะไร
3. **คำถามสำรวจอารมณ์และความรู้สึกเชิงลึก:** การที่น้องยังหาความชอบไม่เจอหรือไม่รู้ว่าจะเข้าคณะไหนน้องมีความรู็สึกอย่างไรกับตัวเองในตอนนี้
4. **คำถามหาเป้าหมายและความสนใจ:** เป้าหมายในอนาคตหลังจบมหาลัยของน้องคืออะไร
5. **คำถามค้นหาปัญหาและความกดดัน:** ในกระบวนการเตรียมตัวเข้ามหาลัยตอนนี้น้องรู้สึกหนักใจหรือเครียดกับอะไรที่สุดและเพราะอะไร
